# Stallfeed

Public support, terms, privacy and disclaimer pages for Stallfeed, a Framer plugin by Sim0 LLC (Florida) that syncs a maker's shop listings to their Framer site.

Served with GitHub Pages from the `main` branch root. Plain static HTML and CSS, no build step.
